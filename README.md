mend is one patch tool for every edit format an AI model writes: unified diffs, SEARCH/REPLACE blocks, V4A patches and JSON edit operations, applied to a tree of files all-or-nothing. Context lines are matched at three tiers — exact, trailing-whitespace-insensitive, then fully whitespace-normalised — so patches whose line numbers have drifted or whose whitespace has shifted still land where they belong, and a file the patch moves is reported as a move. On the kit's practice set of 100 checks it scores the maximum 1000.

## Run it

```sh
node main.ts [options] [PATCH]
```
